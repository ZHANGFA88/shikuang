# SPEC-SENTIMENT — 情绪层（方向 / 把握度 / 等级 / S 分数）

> 定版：2026-10-26 owner 亲令立项，样板先行（树图 + 日历）。
> 本文件为情绪层规格真源；实现细节（表名、迁移号）由后端组映射，字段名与公式不得擅改。

## 1. 单条字段（分析输出新增，逐条 LLM 判定）

| 字段 | 枚举 / 范围 | 说明 |
|---|---|---|
| `sentiment_dir` | `POS`（利多）/ `NEG`（利空）/ `NEU`（中性） | 对市场整体的方向判断，非对个股个案；无法判断 → `NEU` 并降把握度 |
| `sentiment_conf` | 0–1，两位小数 | 把握度；无把握不得写 1.0；`NEU` 的把握度同样必填 |
| `impact_grade` | `S` / `A` / `B` / `C` | 系统级/宏观冲击 → S；板块/行业级 → A；公司/事件级 → B；轻量资讯 → C |
| `impact_reason` | 文本 ≤ 120 字 | upstream 传导链：事件 → 渠道 → 受影响面；禁止写「因为利好所以利好」式空话 |
| `sentiment_evidence` | 可选，文本锚点 | 支撑方向判断的关键句 / 公开来源核对位（如「Key Takeaways 第 2 条」形态）；无则空 |

- 判定口径：方向看**市场影响**，不是事件好坏（如油价上涨对股市偏空、对油气股偏利多时，以大盘方向为准，并在理由中写明另一面）。
- 与现有精选口径不冲突：情绪字段是描述性统计，**永不进入精选/日报主链的推荐逻辑**；精选 sig 压制规则不变。

## 2. 聚合公式（后端聚合层唯一口径，前端只展示）

- 方向分：`POS=+1`，`NEU=0`，`NEG=-1`。
- 权重：`w = sentiment_conf × 等级权重`，等级权重 `S=4, A=3, B=2, C=1`。
- **S 分数**：`S = Σ(方向分 × w) / Σw`，范围 [-1, 1]，展示两位小数。
- **有效样本**：当日（或当主题）覆盖条目中 `sentiment_dir` 非空的条数；**参与率 = 有效样本 / 当日覆盖**。
- **有效样本不足**：有效样本 < 5 时，S 照常算但展示置灰并附注「有效样本不足」，不得只给裸数。
- **边际**：`边际 = S(本期) − S(上期)`；日视图上期 = 前一日；主题视图上期 = 该主题前一日；上期无数据则边际为空，不写 0。
- **利多/利空/中性参考值**：三类有效样本占比（按条数，不按权重），三数之和 100%。

## 3. 树图（主题热力）

- 一块 = 一个主题；块面积 ∝ 该主题加权票数 `Σw`；块色 = 块内主方向（按 `Σw` 分方向取最大者）；颜色深浅 ∝ 块内加权票总量（同色系三档）。
- 块内文案：主题名、篇数、出现次数、S 值；有效样本不足的块附注该句。
- 图例必写：块色按主标签加权多数、颜色深浅表示块内加权票总量；方向色义见 §5。

## 4. 日历

- 月视图格子：日号、当日条数、当日主方向箭头（↑利多 / ↓利空 / →中性）、三色小点（利多/利空/中性条数占比示意）。
- 无数据日明写「暂无数据」，不得留空或借用邻日数据；历史缺口诚实展示（新字段上线前的日期天然无数据）。

## 5. 颜色与诚实标签（样板默认值，生产前 owner 可改）

- 样板默认沿参考惯例：**红 = 利多、绿 = 利空、黄 = 中性**（A 股习惯）；与观潮现行「红 = 命中」语义冲突处，图例与首屏必须明示，样板交付时把冲突点写进报验。
- 全站情绪面统一挂「临时」标；S 分数、边际、参考值下方附一句话：**情绪统计，非交易信号，不构成仓位建议**。仓位栏样板期只写「立场待确认」占位，不做持仓联动。

## 6. 样板范围（本轮只做这些，不进生产）

- 后端：字段 + 分析提示词 + 迁移 + 聚合端点（日聚合、主题聚合、日历聚合）；样板数据窗 ≥ 7 天真实条目（云端真栈实跑，不许 mock 数）。

## 7. 周期语义（A 股宏观上下文标签，2026-10-31 TSP 学习引入）

- 定位：**叠加在现有 S 分体系之上的宏观周期上下文标签，不替代现行打分**。
  S 分回答"今天情绪多强"，周期标签回答"市场处于情绪周期什么位置"。
- **A 股限定**：机制依赖涨停板梯队口径；美股无涨停板，**此机制不适用于美股标的**，
  美股日历格不打周期标签。
- 新增字段（日频，**后端确定性任务产出，非 LLM 判定**）：
  `regime_phase ∈ {ice 冰点, ignite 启动, rally 主升, climax 高潮, ebb 退潮, repair 修复}`；
  输入指标字段（与 TSP 同名，便于对照）：`max_boards（高度）`、`first_board（首板）`、
  `ge2_count（宽度）`、`promo_rate（晋级率）`、`seal_rate（封板率）`。
- 判定规则（驱动量先经 EMA 平滑 alpha=1/3；阈值常量集中声明；**标定自 TSP 2020-08~2026-08
  口径，观潮接入后用自有数据重标定**）：
  - 高潮：`ge2 ≥ 50` 或 `首板 ≥ 220`；
  - 主升：A `高度 ≥7 且 ge2 ≥15 且晋级率 ≥0.23`；B `晋级率 ≥0.30 且高度 ≥5 且 ge2 ≥12`；
  - 冰点：`高度 ≤4 且 ge2 ≤6 且首板 ≤24` 同时贴地；
  - 退潮：A `5 日前确有高位（ge2_prev ≥12 或 h_prev ≥6）且晋级率 ≤0.15 且宽度回落`；
    B `晋级率 ≤0.13 且封板率 ≤0.57` 双弱；
  - 启动：A `ge2 − ge2_prev ≥3 且 ge2 ≥8 且晋级率 ≥0.20`；
    B `高度抬升 ≥1 且高度 ≥5 且晋级率 ≥0.19`；
  - 修复：兜底。
  判定优先级：高潮 → 主升 → 冰点 → 退潮 → 启动 → 修复
  （冰点先于退潮：长期死市不应被标成自高位退潮）。
- 持续性设计：① EMA 平滑（缺失前向填充）；② **2 日确认**（新标签需连续 2 日出现才切换）；
  ③ **弱档否决**：当日大盘弱势（以观潮现有指数/大盘口径定义）时，主升/高潮/启动一律降为修复。
  - 语义顺序（2026-10-31 架构锁定）：**先按候选相位做 2 日确认，再逐日施加弱市否决降级**。
    否决日不计入确认 streak 的反例不采用——即某日候选被否决降级，不影响相邻未否决日的确认计数。
    实现口径：弱市 = 全市场上涨家数占比 < 0.25（`WEAK_ADVANCE_RATIO` 集中常量，
    取自有日 K 全市场统计，零外部依赖）。
- 涨停判定口径（与连板梯队共用，SPEC-DATATOOLS §6.1）：
  `raw_close（未复权） ≥ 交易所半上取整涨停价 − 0.005`；ST/北交所按板块代码分档；
  ST 规则变动史以交易所最新规则为准、阈值可配置；新股无涨跌幅限制窗口不参与计数且阻断连续链。
- 展示：日历格追加阶段色带/标签；阶段段列表接口（起止、天数、指标均值）。
- 诚实标签：页内明示「约 74% 交易日为修复（无可辨认周期位置），属预期行为」。
- 主线排名（概念/行业）：**暂不进首版**（依赖概念映射快照，观潮暂无该数据），列为远期候选；
  若做，宽基过滤（成员数上限/黑名单）与快照偏差声明（`membership_note` 式）一并移植。
- 前置：**A 股日 K 管线**（keyless 源、零货币成本：开高低收 + 股票名称含 ST 标记 + 板块代码规则；
  涨停判定为纯函数，不依赖行情源封单字段）。此管线同时解锁连板梯队、AI 复盘，
  建议立为独立前置任务。
