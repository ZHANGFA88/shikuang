# SPEC-DATATOOLS — 数据工具（热力图 / AI 投研助手 / 选股器 / 暗池追踪）

> 立项：2026-10-29 owner 对标 IUX24 亲点"全上"（暗池用免费延迟版，禁买付费实时数据）。
> 本文件为四工具规格真源；P2 两个日历见 §6。实现细节（表名、迁移号）由后端组映射，
> 数据源字段可用性以后端实测为准，字段名与口径公式不得擅改。

## 0. 总则（四工具通用铁律）

- 审美：报纸风唯一；口径：全中文；成本：**零新增**（除既有 qwen3.7-plus 模型调用外，
  不新增任何付费数据源、付费 API、付费 Key）。
- 交付纪律：云端样板栈先跑通 → 架构验 → 进生产；样板期不动生产路由与生产文件。
- 落位：新导航项「数据工具」，页面 `/data/heatmap`、`/data/assistant`、`/data/screener`、
  `/data/darkpool`；首页入口条待样板评审时定（不扰动已冻结的观测台 UI）。
- 落位方式：四个工具各做成 `modules/` 下独立模块（`modules/heatmap`、`modules/ai-assistant`、
  `modules/screener`、`modules/darkpool`）；所有公开读取出口一律走
  `packages/backend/src/publication/`；模型调用只在 worker 任务内——**AI 投研助手为例外，
  见 §2 裁定**；迁移放模块 `migrations/`，遵守 0055 起一文件一条在线语句、不改已发布迁移。
- 诚实标签：四个页面各有自己的数据口径声明（见各节），一律明示延迟/快照时间，
  一律不包装成交易信号。

## 1. 市场热力图（P1-①）

- 指数板：沪深 300 / 恒生指数 / 纳斯达克 100 / 标普 500，四板可切。
- 成分表：免费端点成分名单，服务端缓存、**日更**（盘后刷新一次）。
- 行情源链（keyless，免注册）：新浪 `hq.sinajs.cn` → 腾讯 `qt.gtimg.cn` → 东财
  `push2.eastmoney.com`；源级故障自动降级，降级事件记日志不打扰读者。
- 渲染：块面积 ∝ 总市值，块色 = 涨跌幅（**红涨绿跌**，A 股/港美统一此惯例，图例明示），
  深浅 ∝ 涨跌幅绝对值；**复用情绪树图样板代码**（布局算法与交互骨架）。
- 刷新：盘中服务端缓存 5 分钟；页首明示「免费行情，快照时间 HH:MM，非实时逐笔」。
- 熔断：任一源连续失败 N 次则该板显示「行情源暂不可用」，不拿旧快照冒充实时。

## 2. AI 投研助手（P1-②）

- 形态：问答框，只基于**观潮新闻库**回答（articles + analyses + 已发日报全文）；
  检索 top-K 后由 qwen3.7-plus 作答，复用现有调用链。
- **例外裁定**：读者提问触发模型调用，与仓规"模型只在 worker 内"冲突。
  架构特批本模块为例外，条件：① 每次调用走 `providers/receipts.ts` 回执与预算熔断；
  ② 单次问答 token 上限（含检索上下文）写死；③ 每日调用次数上限；④ 超限时如实返回
  「今日问答额度已用完」，不静默降质。本裁定仅适用于本模块，不扩散。
- 回答铁律：首尾必挂「AI 生成、非投资建议」；每条关键结论附引用（标题 + 站内链接）；
  库中无依据的问题必须明说「观潮库中暂无相关收录」，**禁编造**；输入长度上限，
  注入式提问（套取系统提示词等）直接拒绝并记录。
- 样板先验：用 20 个真实问题跑一遍，抽查引用可达率与"无依据明说"行为，报告附样板。

### 2.1 交互机制修正案（2026-10-31，TSP 学习引入，只加不改现有铁律）

- **引用足迹卡**：检索过程以一行摘要展示（检索策略 keyword/vector、候选池 N、top-K），
  每条引用为一张卡：`{title, date, url（站内）, anchor（证据锚点）, snippet（可展开原文片段）}`；
  dry-run 时摘要行如实标注「[dry-run] 模型调用已跳过」。引用足迹**不计入模型上下文**（省 token）。
- **合规声明前端固定渲染**：回答卡片组件内写死 header/footer「AI 生成、非投资建议」，
  不依赖模型自觉追加；模型输出禁重复追加该句。
- **工具白名单**：助手可调用的检索工具列表写死在后端配置；注入式提问沿用现有
  「直接拒绝并记录」。
- **会话容量纪律**：单用户 ≤ 20 会话 × 每会话 200 消息；足迹不入上下文。
- **预留"动作工具"扩展位**：将来若加订阅/收藏类动作，沿用确认卡三要素
  （动作名 + 一句话风险说明 + 完整待执行参数 JSON）+ 120s 超时（拒绝≠超时文案区分）
  + 默认关闭的免确认开关（fail-closed）。**本期不启用**（本助手零动作工具）。

## 3. 选股器（P1-③）

- 数据源（keyless）：东财 `push2.eastmoney.com/api/qt/clist` 为主（含 P/E、市值、
  涨跌幅等字段，以后端实测字段为准），新浪/腾讯为备；**严格遵守免费档调用上限**，
  服务端缓存 + 请求合并，禁止前端直连刷接口。
- 范围：A 股全市场 + 港股主板 + 美股（纳斯达克 100 / 标普 500 成分）；范围过大导致
  缓存失速时，架构有权砍范围保体验。
- 筛选字段（首版）：市盈率 TTM、市值、当日涨跌幅、5 日涨跌幅、换手率；
  字段以数据源实测可用为准，不硬凑没有的字段。
- 页首明示：快照时间 + 「基于免费行情/基本面数据，非投资建议」。

## 4. 暗池追踪（P1-④，免费延迟版）

- 数据源：**FINRA ATS 周度文件**（finra.org 公开下载，免费），worker 周任务拉取、
  解析、入库；**红线：禁买任何付费实时暗池数据源**（owner 明确不花钱），此条为硬约束，
  违反即打回。
- 范围：美股 NMS 标的（FINRA ATS 口径内）；A 股/港股无公开暗池数据，页面明示范围。
- 页面：个股搜索 + 周度 ATS 成交量/占比柱状 + 趋势表；页首与每图下方明示
  「FINRA ATS 周度数据，**延迟约两周**，仅供趋势参考，**非实时信号**」。
- 延迟口径是本页的生命线：数据周次、发布日期、延迟天数三项必须同时展示，
  缺一即为不合格样板。

### 6.1 TSP 学习新增 P2 候选（2026-10-31，架构裁定）

- **连板梯队：批准为 P2 候选**，与财报日历排队（A 股特色，owner 对 A 股刚需敏感）。
  口径（写死进 spec，不许含糊）：涨停判定 `raw_close（未复权） ≥ 交易所半上取整涨停价 − 0.005`；
  N 连板 = 截至最新交易日的连续涨停天数，**断板即清零**；一字板计入连板数、仅展示层打「一字」标记；
  ST/北交所按板块代码分档（10%/20%/30%），ST 规则变动史以交易所最新规则为准、阈值可配置；
  口径声明（断板清零、一字板计入）必须前置明示。端点 `GET /api/site/limit-ladder?date=`。
  前置：A 股日 K 管线（与 §7 周期语义同一管线，见 SPEC-SENTIMENT §7）。
- **盘后 AI 复盘：P2 候选**，定位为日报的**行情数据驱动互补视角**，**不进精选/日报主链推荐逻辑**
  （情绪层铁律同样适用）。输入装配照搬八项（复盘日期、主要指数、盘面数据、市场情绪、
  概念/行业 top5、龙虎榜资金动向、盘前风向标对照、近期新闻——新闻项用观潮新闻库，
  这是观潮相对 TSP 的优势）；输出固定八节模板；**硬红线逐字移植**：禁输出进攻/防守/
  加仓/减仓/仓位/低吸/追高等一切交易指令，只做客观陈述；末尾前端固定渲染
  「AI 生成、非投资建议」。调用复用既有 qwen3.7-plus 链（worker 内，receipts + 熔断）。
  首版不做：五档封单修正、封单监控报警（交易信号暗示）。
- **能力路由矩阵：P2+ 架构演进项**（本期不动现有源链）。方向：观潮数据需求拆成独立能力
  （`realtime_snapshot` / `daily_kline` / `financial` / `constituent_list` 等），集中声明每能力的
  候选源与默认源；publication 层入口定义标准口径（change_pct 小数制、volume/amount 单位、
  时间时区），抓取侧负责换算，上层只吃标准口径；**禁启发式单位猜测**（fail-closed）；
  每能力以"生效源当前真实可用"为准，全挂时页面显示「数据源暂不可用」，不拿旧快照冒充。
- **明确不借**（定位冲突，封存不再议）：策略引擎 / 回测 / 因子平台 / 因子挖掘 / 监控告警推送 /
  模拟盘 / 盘中分钟 K·五档盘口基建 / MCP / 扩展页面插件。观潮是情报站，「非交易信号」红线不动。
